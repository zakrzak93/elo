# Framework -- Thumbnail (koncept)

Skill nie renderuje miniatury, ale **opisuje koncept** który grafik może wykonać. Opis w `pomysl.md` ma zawierać kategorię, focal point, emocję, kolory i maks 2-3 słowa tekstu.

## Planowanie

Obejrzyj finalny materiał / przeczytaj źródło, odpowiedz:
- Najmocniejszy moment? (timestamp albo fragment)
- Główna emocja?
- Unikalny hak ciekawości?
- Oczekiwana reakcja widza?

## Kategorie i zastosowanie

1. **Collage (29%)** -- wiele elementów, historia. Np. składniki + danie + reakcja.
2. **Showcase (25%)** -- produkt / ujawnienie. Np. rozpakowywanie z ostrym focusem na rzecz.
3. **Reaction (24%)** -- wyzwania, testy. Np. zszokowana twarz + drogi przedmiot.
4. **Split frame (11%)** -- before/after, porównania. Np. amator vs profesjonalista.
5. **Single action (10%)** -- kluczowy moment. Np. dokładny moment sukcesu/porażki.

## Must-have

- Jeden focal point
- Silna emocja jeśli jest twarz
- Wysoki kontrast
- Czyste tło
- Maks 2-3 słowa tekstu
- Czytelne na telefonie

## Do unikania

- Zagracona kompozycja
- Mały tekst
- Zajęte tło
- Więcej niż 3-4 obiekty
- Elementy w prawym dolnym rogu (tam pojawia się timestamp)

## Kompozycja

- Zasada trójpodziału, bohater na lewej lub prawej tercji
- Tekst wyrównany do punktów siatki
- Oddech przy krawędziach

## Tekst

- Font min 100pt
- Bold sans-serif
- Outline 4-8px czarny na białym
- Dobre: "NIEMOŻLIWE!", "BŁĄD ZA 10 000"
- Złe: całe zdanie

## Kolory

- Wysoka energia: żółte tło + czarny tekst / czerwone tło + biały tekst
- Profesjonalny look: granat + biały
- Dramatyczny: ciemny gradient + jasny akcent

## Format opisu w `pomysl.md`

```
Thumbnail: [kategoria]. [Focal point opis]. Tekst na miniaturce: "[2-3 SŁOWA]".
Paleta: [opis kolorów]. Emocja: [szok/ciekawość/pożądanie].
```
