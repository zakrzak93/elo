# Framework -- Intro / Hook

## Pre-produkcja

Najpierw **TNT** (Title + Thumbnail). To ustawia oczekiwania widza.

Trzy rdzenne elementy:
- **Bohater** -- widz sam albo ktoś w materiale
- **Koncept** -- o czym to jest
- **Stawka** -- co widz straci lub zyska

## Pierwsze 5 sekund

- Pierwsze zdanie dokładnie matchuje tytuł
- Pierwszy kadr dokładnie matchuje miniaturkę
- Natychmiastowa wiarygodność (dowód, liczba, obraz)

Źle: "Hej, witam w kolejnym odcinku, dzisiaj porozmawiamy o..."
Dobrze: Konkretny fakt, dowód, albo obraz z miniaturki + zdanie matchujące tytuł.

## Struktura hooka (20-30 sekund)

1. **Otwarcie** -- matchuje tytuł
2. **Wiarygodność** -- dlaczego my, dlaczego teraz
3. **Luka ciekawości** -- otwarta pętla, pytanie bez odpowiedzi
4. **Włożony wysiłek** -- "po analizie X", "po 3 miesiącach", dowód pracy
5. **Obietnica wartości** -- co widz dostanie

## Zmiana wizualna co 1.5-2 sekundy

Nawet w skrypcie pod lektora hook powinien mieć sugerowane cuty / change-upy:
- Archiwum
- Screen
- Wykres / liczba
- Twarz (reakcja)
- Before/after

## Zabójcy retencji (NIE RÓBMY TEGO)

- Długi plug kanału na starcie
- Zbędny backstory
- Wolne tempo
- Brak jasnego celu
- Za dużo kontekstu przed wartością
- Niska energia

## Checklist intro

- [ ] Długość intro: 20-30 sekund maksimum
- [ ] Pierwsze zdanie matchuje tytuł
- [ ] Pierwszy kadr matchuje thumbnail
- [ ] Jasna luka ciekawości
- [ ] Ustawione stawki

- [ ] Naturalny flow
