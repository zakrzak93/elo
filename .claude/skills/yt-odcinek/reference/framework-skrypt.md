# Framework -- Skrypt pod lektora

## Fundament strategiczny

**Avatar widza:**
- Demografia
- Stan obecny
- Bolączki
- Poziom wiedzy
- Cele
- Język jakiego używa

Odpowiedz sobie: co nie daje mu spać, czego już próbował, co myśli że potrzebuje vs co naprawdę potrzebuje.

**Cel odcinka:**
- Tytuł
- Główna transformacja (z czego -> do czego)
- Kluczowe wnioski
- Mapa emocjonalna: Zdezorientowany -> Rozumiejący -> Pewny -> Podekscytowany -> Działający

## Struktura

### Hook (pierwsze 30 sekund)

Typy hooków:
- **Pytanie** -- "Chcesz wiedzieć, dlaczego niektórzy X..."
- **Szokujące stwierdzenie** -- "90% ludzi robi błąd X"
- **Historia** -- "Trzy miesiące temu byłem gotów się poddać"
- **Zapowiedź** -- "W następnych 10 minutach pokażę..."

### Korpus -- każdy punkt ma strukturę

1. **Otwarcie pętli** -- "Zanim pokażę tę zmianę..."
2. **Dlaczego to ważne** -- "To może podwoić X, bo..."
3. **Czym to jest** -- ujawnienie koncepcji
4. **Jak wdrożyć** -- konkretne kroki
5. **Dowód** -- "Zobacz, jak [imię] zrobił..."
6. **Przejście** -- most do następnego punktu

## Techniki zaangażowania

- **Napięcie/rozwiązanie** -- "Większość myśli [powszechne przekonanie]... ale tak naprawdę..."
- **Widz czuje się sprytny** -- "Spójrz na ten wykres... zauważasz coś? No właśnie..."
- **Storytelling** -- "Zobacz jak Ania poszła z zera do stu tysięcy"

## Budowanie wartości

Struktura mini-payoffów:
- Mały win -> "Pierwszy sukces"
- Problem -> "Blokada"
- Odkrycie -> "Co zauważyłem"
- Testy -> "3 miesiące prób"
- Rozwiązanie -> "Strategia która zmieniła grę"
- Duży payoff -> "Pierwszy [duży wynik]"

## Elementy produkcyjne

**B-roll:** screen recordings, pokazy, przykłady z życia, grafiki
**Tekst na ekranie:** kluczowe statystyki, cytaty, numery kroków
**Pacing:** zmiana wizualna co 1.5-2 sekundy

## Zasady pisania

**Zawsze:**
- Kontekst przed koncepcją
- Przykład po wyjaśnieniu
- Dowód po twierdzeniu
- Rozwiązanie po napięciu

**Nigdy:**
- Oddanie kluczowej pointy za wcześnie
- Niewyjaśnione terminy techniczne
- Pytania bez odpowiedzi
- Przepychanie ważnych przejść

## Optymalizacja językowa (PL)

Zamień drętwe na żywe:
- "Wykorzystać" -> "użyć"
- "Wdrożenie" -> "zacząć używać"
- "Metodologia" -> "sposób"
- "Następnie" -> "potem"
- "Rozpocząć" -> "zacząć"

## Proporcje

- Hook: 30s -> ~80-100 słów
- Korpus: 5-7 bloków x ~400-500 słów = 2500-3000 słów
- Zamknięcie: 30-60s -> ~100-150 słów

Łącznie: 2900-3200 słów.

## Checklist skryptu

- [ ] Hook adresuje ból widza
- [ ] Obietnica postawiona wcześnie
- [ ] Płynne przejścia
- [ ] Konkretne przykłady
- [ ] Prosty, mówiony język
- [ ] Logika zachowana
- [ ] Twierdzenia wsparte
- [ ] Czytanie na głos brzmi naturalnie
