# Framework -- Tytuł

## Zasady

- Wyzwala przynajmniej jedną z trzech emocji (idealnie dwie)
- Jasny i łatwo zrozumiały
- Dotrzymuje obietnicy
- Ważne słowa z przodu
- Maks 55 znaków

## Trzy emocje i skuteczność

- **Ciekawość** (60% viralowych) -- otwiera pętle, tworzy pytania, obiecuje sekrety
- **Pożądanie** (46%) -- obiecuje korzyści, transformację, rozwiązanie
- **Strach** (39%) -- błędy, pilność, straty

## Szablony

**Problem-Rozwiązanie:**
- [Problem]: Oto rozwiązanie
- Dlaczego [sytuacja] nie działa (zrób to zamiast)
- Przestań [błąd] i zacznij [rozwiązanie]

**Autorytet:**
- [Ekspert] ujawnia [sekret tematu]
- Były [zawód] pokazuje [insider info]
- Czego [eksperci] ci nie mówią o [temat]

**Osobiste doświadczenie:**
- Testowałem [X] przez [czas] -- oto co się stało
- Jak [osiągnąłem] w [czas]
- [X] rzeczy, których żałuję, że nie wiedziałem przed [aktywność]

## Elementy wzmacniające

- Liczby (nieparzyste często lepsze)
- Rok (zwłaszcza Q1)
- Nawiasy (dopisek)
- Słowa mocy: ujawnione, sekret, ukryte, niewiadome
- Czas: dzisiaj, teraz, zanim

## Pisanie -- 5 wersji zawsze

1. Ciekawość + Strach
2. Ciekawość + Pożądanie
3. Korzyść
4. Element czasu
5. Autorytet

## Red flagi

- Clickbait bez dostarczenia
- Kilka tematów w jednym
- Żargon
- Ogólne obietnice
- Powtarzanie tekstu z miniaturki
- Łączenie przez "i" dwóch odrębnych tematów
- Za długie

## Wzorce które działają

**Czas:**
- "Jedyna strategia [temat] której potrzebujesz w 2024"
- "Dlaczego wszystko w [temat] zmieni się w 2024"

**Kontrast:**
- "[Mało zł] danie smakujące jak [dużo zł]"
- "Jak zarobiłem [X] pracując mniej godzin"

**Sekret:**
- "Prawda o [temat], o której nikt nie mówi"
- "Ukryte funkcje [platformy] o których nie wiedziałeś"

## Checklist tytułu

- [ ] Poniżej 55 znaków
- [ ] Ważne słowa z przodu
- [ ] Jasna wartość
- [ ] Emocja obecna
- [ ] Zgodny z treścią
- [ ] Konkretna obietnica, nie mglista
- [ ] Nie powiela tekstu z miniaturki
